# S01E01

## Введение

- Дата центры Яндекса подвергнулись атаке беспилотников
- Яндекс Такси вышло из строя
- Почему бы не сделать Яндекс Такси децентрализованным
- Без серверов, без комисий, без дата центров -- все равны
- Технология -- Veilid -- p2p фреймворт на Rust для создания децентрализованных анонимных приложений

## Архитектура

- Начинаем с публикации заявок на перевозку в Veilid
- В Veilid есть DHT --- это большая таблица размазанная на всех клиентов
- В эту тублицу по ключу пишем заявку на такси
- Так как приложение без серверов, мы пишем в таблицу равноправно от всех участников
- Криптогнрафический ключ ячейки в которую пишем запрос считается по формуле -- герорафическая ячейка + время 
- Все могут писать в эту ячейку. Количесво записей в ячейке огранчиено, вводим шардинг
